Window restore reopens every Paseo desktop window you had open when Paseo last quit, and puts each one back on its own workspace with its own sidebar Host and Project filters, theme, and position.

Windows can also have custom names, which are hidden by default. Turn off **Hide window names** in the plugin's settings to use them. Then select **Name this window** at the top of the sidebar, or search for **Rename this window** in the Command Center, to name a window. The name appears in the operating system's window title and returns with that window after a restart. Turning names back off hides them without deleting them.

Paseo normally reopens a single window, and every window shares one saved sidebar filter and theme. This plugin records each window's route, sidebar filters, theme, position, and name while it is open. When the first window of a new launch loads, it opens the other windows one at a time, and each reloads into its saved state. Windows you closed before quitting are not reopened. **Restore windows from last session** in the Command Center (⌘K) runs the same restore on demand.

Desktop app only (macOS, Windows, Linux) and requires Paseo 0.14.0 or newer. It relies on desktop internals that are not part of the plugin API: the `sidebar-view` and `@paseo:app-settings` local storage keys, the app's route format, and the desktop New Window bridge. A Paseo update can change any of these. Windows reopen on the current desktop or Space, and positions are restored only where the operating system allows it. Everything is stored in the app's local storage; nothing leaves the machine.
