Window restore reopens every Paseo desktop window you had open when Paseo last quit, and puts each one back on its own workspace with its own sidebar Host and Project filters, position, and custom name. Select **Name this window** at the top of the sidebar to name it. The name appears in the operating system's window title and returns with that window after a restart.

Paseo normally reopens a single window, and every window shares one saved sidebar filter. This plugin records each window's route, sidebar filters, position, and name while it is open. When the first window of a new launch loads, it opens the other windows one at a time, and each reloads into its saved state. Windows you closed before quitting are not reopened. **Restore windows from last session** in the Command Center (⌘K) runs the same restore on demand.

Desktop app only (macOS, Windows, Linux) and requires Paseo 0.14.0 or newer. It relies on desktop internals that are not part of the plugin API: the `sidebar-view` local storage key, the app's route format, and the desktop New Window bridge. A Paseo update can change any of these. Windows reopen on the current desktop or Space, and positions are restored only where the operating system allows it. Everything is stored in the app's local storage; nothing leaves the machine.
